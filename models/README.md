## Загрузка весов (чекпоинтов) модели

download_ckpts.sh - загружает модель из официального репозитория SAM2

download_yandex.sh - загружает модель альтернативно с yandex-диска  
  
В результате запуска
```bash
./download_ckpts.sh
```

или

```bash
./download_yandex.sh
```

в папке models должен появиться файл sam2.1_hiera_large.pt
