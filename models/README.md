## Загрузка весов (чекпоинтов) модели

1. Скрипты для загрузки весов модели  

download_ckpts.sh - загружает модель из официального репозитория SAM2 (ссылка бывает недоступна из-за сетевых проблем)

download_yandex.sh - загружает модель с yandex-диска (ссылка работает не гарантировано)
  
В результате запуска
```bash
./download_ckpts.sh
```

или

```bash
./download_yandex.sh
```

в папке models должен появиться файл sam2.1_hiera_large.pt


2. Альтернативный вариант: скачать файл весов через браузер.  
Файл положить в папку models.

```
https://disk.yandex.ru/d/cMsiauLhyvhsgg
```
